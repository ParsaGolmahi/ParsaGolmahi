### 🧬 My Expertise: Fine-Tuning & Training LLMs

As an LLM developer and enthusiast, I specialize in:

- 🎯 **Fine-Tuning**: Customizing 7B–13B models with PEFT and LoRA on domain-specific datasets.
- 🧪 **Model Training**: Building datasets, tokenization, and rigorous evaluation pipelines.
- 📦 **Local Deployment**: Running models on consumer hardware using Ollama and ONNX.
- 🔗 **RAG & Agents**: Combining LLMs with vector databases for intelligent, context-aware responses.
